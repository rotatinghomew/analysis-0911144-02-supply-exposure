# 业务资料口径

每个 node 的 capacity 是同一分析时段可消耗总量；终端订单也消耗该节点产能。边 parent→child 表示生产一单位 parent 所需的 child 数量 units。同一 parent 内不同 group 都需满足；同一 group 的不同 child 是经过认证的替代来源，可分配但不能突破共享容量。valid_from 为认证可用的整数日。当前 records 查询只显示关系，不把可达性当成可供量。中断情景、未知来源和分配目标必须成为分析输入的一部分；资料没有给出的概率或优先级不能自行补成事实。

小样本用于手工核对字段和边界；历史样本只扩展观测量，不保证任何推断、优化或方案一定成立。实际分析应允许信息不足或条件冲突。

中断暴露分析口径：同一 parent 的不同 group 是并行部件，必须同时满足；同一 group 的不同 child 是可互换来源，按各自 units 折算后合并使用，二者不可混为一谈。节点产能是全情景共享的时段总量，所有订单、所有路径共用，不重复计数。分析只给出三分结论：可确认（已生效认证与已登记产能足以支持）、无法确定（依赖未生效认证、情景声明的未知来源或循环转包的部分，只给上限）、确定缺口（即使按最宽口径也无法满足的部分）。不给任何路径赋予概率，不把单项恢复累加成整单恢复；整单恢复要求所有部件组均可确认。停供按窗口与分析期重叠天数线性扣减产能；分配先求总量最大再拉平最低满足率，优先级只能来自情景输入 fulfill_first，资料没有给出的优先级不自行补成事实。交付日在分析期外的订单不纳入核算，单独列出。
