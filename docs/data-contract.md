# 业务资料口径

每个 node 的 capacity 是同一分析时段可消耗总量；终端订单也消耗该节点产能。边 parent→child 表示生产一单位 parent 所需的 child 数量 units。同一 parent 内不同 group 都需满足；同一 group 的不同 child 是经过认证的替代来源，可分配但不能突破共享容量。valid_from 为认证可用的整数日。当前 records 查询只显示关系，不把可达性当成可供量。中断情景、未知来源和分配目标必须成为分析输入的一部分；资料没有给出的概率或优先级不能自行补成事实。

小样本用于手工核对字段和边界；历史样本只扩展观测量，不保证任何推断、优化或方案一定成立。实际分析应允许信息不足或条件冲突。
